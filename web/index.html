aiinfo-humanize

Inspect and remove AI-provenance metadata (C2PA, EXIF, XMP, generator prompts) from PNG, JPEG and WebP images.

🔒 Runs entirely in your browser. Images are never uploaded.

    How it works

    The tool removes metadata blocks directly from the file structure without re-encoding the image, so pixels and quality stay exactly the same. EXIF orientation is kept so photos don't rotate.

    Limitations

    Only metadata is removed. Invisible pixel-level watermarks (for example Google SynthID) are part of the image itself and stay. AI detectors may still recognise generated images from how they look.

    Responsible use

    Good for privacy, smaller files and personal projects. Don't use it to pass off AI images as real photos or as your own hand-made work where disclosure is expected.
